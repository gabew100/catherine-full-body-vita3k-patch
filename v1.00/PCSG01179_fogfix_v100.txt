# Catherine: Full Body (PCSG01179), v1.00 eboot. Do not use with the English rePatch or v1.03 eboot.
# Fixes the freeze on the "Stage 3 Torture Chamber" card at the start of night 3 (Vita3K issue #3002,
# endless "Invalid read of uint32_t at address: 0x4c").
#
# The game has no runtime shader compiler. Two caches, filled from the precompiled shaders in Shader.cpk
# and keyed by the material key, give a material its shaders (0x81320e98) and its vertex+fragment program
# pair (0x81321144). Their create functions are stubs returning 0, so a key that is not in the cache gets
# a NULL program. On night 3 a job thread builds the Nightmare model's material keys before the
# Nightmare environment turns fog off, so it asks for a fog variant (0009c010/01408933) that is not in
# the caches. On hardware that job is slower and fog is already off when it gets there.
#
# For both caches this rewrites the miss path: retry once with the fog bits cleared (key word 1 bit 0 and
# the fog mode bits 0x33000000 of word 2, which the key builder only sets when fog is on), then run the
# original miss code. To make room, three stores of 0 into the node that was just memset are dropped and
# one base address load is computed from the lock pointer. Lookups that hit are unchanged.
# Generated and checked against the original code by fog_fallback.py.
#
